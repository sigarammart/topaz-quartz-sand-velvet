Shows a fixed Install XP App bar on xplorepondy.com.

== Installation ==
1. Upload this zip in WordPress → Plugins → Add New → Upload Plugin
2. Activate XP App Install Button
3. Visit https://xplorepondy.com on a phone — the Install bar appears at the bottom
